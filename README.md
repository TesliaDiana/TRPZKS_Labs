Simple Inventory

1. Варіант індивідуального завдання

Номер у групі - 23, тож варіанти для завдання:

V2 = (N % 2) + 1 = (23 % 2) + 1 = 2

V3 = (N % 3) + 1 = (23 % 3) + 1 = 3

V5 = (N % 5) + 1 = (23 % 5) + 1 = 4

  Застосунок: Simple Inventory — сервіс обліку обладнання.
  Спосіб конфігурації: Конфігураційний файл за шляхом /etc/mywebapp/config.
  Порт застосунку: 8000.
  База даних: PostgreSQL.

2. Документацію по розгортанню
  2.1. Де взяти базовий образ віртуальної машини та який образ завантажувати:
    Офіційний образ дистрибутиву: Ubuntu (https://ubuntu.com/download/server/thank-you?version=24.04.4&architecture=amd64&lts=true).
    
    Для перевірки програмного забезпечування використовувати віртуальну машину Oracle VirtualBox.

  2.2. Характеристики віртуальної машини:
    Base Memory: 4096 Мб.
    CPU: 2 ядра.
    Disk Size 35 Гб.

  2.3. Спеціальні налаштування при встановленні OS на віртуальну машину:
    При створенні, третій рядок, де папка і можна ввести свій iso треба зайти і "інше" і знайти наш встановлений дистрибутив. 
    Після створення віртуальної машини треба зайти в "Налаштування" -> "Мережа" -> поставити галочку в "Ввімкнути мережевий адаптер" та в "Attached to" встановити "Проміжний адаптер" (Мережа має виставитись автоматично, але бажано перевірити). Більше ніякі додаткові налаштування не потрібні. Встановлення проведеться автоматично за замовчуванням при наявносіт підключення до мережі Інтернет.

3. Документацію по розробленому веб-застосунку
  3.1. Призначення застосунку
    Як сказано раніше — Simple Inventory — це сервіс обліку обладнання з полями 
      id, 
      name,
      quantity,
      created_at.
    Сервіс може: 
    1) Виводити список усіх предметів в інвентарі (id,name).
    2) Створювати новий запис у системі обліку.
    3) Виводити детальну інформацію по записам в інвентарі (id, name, quantity, created_at).
